# Day 23 - Reading Files

## Topics

- `open()`
- Read mode (`"r"`)
- `readlines()`
- `for` loop
- `strip()`
- `if`
- Counting lines

## Exercises

### Exercise 1
Read all lines from `names.txt` and print them.

### Exercise 2
Search the file and display lines containing `IT`.

### Exercise 3
Count the number of lines in the file.

## Concepts Learned

- `read()` reads the entire file.
- `readline()` reads one line.
- `readlines()` reads all lines and returns a list.
- `strip()` removes extra whitespace and newline characters.
