## Exercises

### Exercise 1
Build a file path using pathlib.

### Exercise 2
Create a file using touch().

### Exercise 3
Write text to a file using write_text().

### Exercise 4
Read file content using read_text().

### Exercise 5
Append text to a file using open("a").

### Exercise 6 - Log Manager

Create a simple Log Manager that:

- Creates the Logs directory if it does not exist.
- Creates Server.log if it does not exist.
- Adds a server start message to the log.
- Reads the log file.
- Displays the log content.
